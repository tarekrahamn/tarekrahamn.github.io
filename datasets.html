    VegQual: A Multiclass Dataset for Real-Time Fresh and Defective Vegetables

    VegQual is a real-world vegetable quality assessment dataset containing 2,032 raw images from seven commonly consumed vegetable species. The dataset includes 14 categories covering fresh and defective classes. Images were collected under diverse real-world conditions with variations in lighting, backgrounds, viewing angles, and object distances. All images were annotated using bounding boxes in YOLO format, producing 4,736 annotated instances for object detection research.

    Figshare Dataset · Object Detection, Agriculture, Food Quality Assessment

    PlasticVision-BD: A Benchmark Dataset for Plastic Waste Detection

    PlasticVision-BD is a real-world annotated dataset developed for plastic waste detection and classification. It contains five major plastic waste categories: Plastic-Bottle, Plastic-Cup, Plastic-Packet, Plastic-Straw, and Polythene. Each object instance is annotated with bounding boxes following a quality-controlled annotation protocol, supporting YOLO, RT-DETR, Faster R-CNN, SSD, EfficientDet, and other computer vision models.

    Mendeley Data · Computer Vision, Waste Detection, Environmental AI

    TextileClass-7: Dataset for Fabric Material Classification

    TextileClass-7 is a fabric image classification dataset containing seven fabric categories: Cotton, Cotton Mixed, Denim, Polyester, Silk, Viscose, and Wool. The images represent real-world variations in illumination, texture, wrinkles, folds, viewing angles, and backgrounds. Each image contains a single class label and is suitable for transfer learning, textile recognition, and intelligent inspection systems.

    Mendeley Data · Image Classification, Textile Recognition, Deep Learning

  • [D4]

    BanglaPulse: A Real-World Multiclass Image Dataset for Bangladeshi Pulse Crop Recognition

    BanglaPulse is a real-world pulse crop object detection dataset containing 2,942 images across 16 pulse crop categories collected from traditional markets in Bangladesh. Images were captured under different illumination conditions, camera angles, distances, and backgrounds. All samples were annotated with bounding boxes and prepared as a benchmark dataset for precision agriculture and food recognition research.

    Figshare Dataset · Object Detection, Agriculture, Smart Farming
